## Art

No third-party sprite sheets ship in this spike. Players and obstacles are
drawn at runtime from Phaser Graphics (colored circles and rounded blocks).

If you drop in bitmap art later, use [Kenney](https://kenney.nl) CC0 packs
only and list the pack name + URL here.

## Agent skills

Official Phaser 4 agent skills are vendored from
[phaserjs/phaser/skills](https://github.com/phaserjs/phaser/tree/master/skills)
into `.cursor/skills`.
