TAG

Focus Otter starter · Phaser 4 + Colyseus

Phones are controllers.
The laptop is the arena.

A reusable multiplayer tag game: one host screen shows the map, every phone joins with a QR code, and the Colyseus server decides who is it. Built so a later talk can drop OpenFGA checks into canTag() and flip rules mid-round.

How it works

  1. Host opens /host on a laptop and creates a room. Guest mode skips login; Auth0 passwordless is still wired for later.
  2. Players scan the QR code, pick a nickname, and drive a virtual joystick.
  3. One random player starts as it. Touching someone passes the tag (with 1.5s tag-back immunity). Two minutes. Least time as it wins.

Rules (server-authoritative)

  • Positions, collisions, tags, and the clock live on the server.
  • Clients only send joystick input.
  • If it disconnects, the room reassigns immediately.
  • Reconnects rejoin the same player slot by guest id or Auth0 sub.
